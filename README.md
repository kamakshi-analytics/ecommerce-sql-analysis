# Brazilian E-Commerce Sales Analysis using MySQL

## Project Overview
This project analyzes Brazilian e-commerce data using MySQL to understand sales performance, product categories, customer purchasing behavior, and delivery performance.

## Business Objectives
- Validate data quality and table relationships.
- Analyze order statuses and delivered product revenue.
- Identify top-performing product categories and customer states.
- Explore monthly revenue trends.
- Analyze repeat customers and average order value.
- Evaluate delivery performance against estimated dates.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
- `customers`
- `orders`
- `order_items`
- `products`

## SQL Concepts Demonstrated
- SELECT, WHERE, ORDER BY
- GROUP BY and aggregate functions
- INNER JOIN and LEFT JOIN
- Common Table Expressions (CTEs)
- CASE statements
- Date functions and DATEDIFF
- Window functions: DENSE_RANK and LAG
- Data-quality validation

## Analysis Performed
1. Order-status analysis
2. Delivered product revenue and freight analysis
3. Monthly sales trends
4. Top product categories by revenue
5. Revenue by customer state
6. Repeat-customer analysis
7. Delivery performance analysis
8. Average order value calculation
9. Category revenue ranking
10. Month-over-month revenue comparison

## Key Findings
Key findings will be added using the actual results from the SQL queries, including sales trends, top categories, customer behavior, and delivery performance.

## Business Recommendations
Recommendations will be based on the observed sales trends, category performance, customer purchasing patterns, and delivery results.

## Limitations
- Product revenue is based on item prices and excludes freight and other payment adjustments.
- Delivery analysis includes orders with the required date fields available.
- Conclusions are limited to the data analyzed.

## Conclusion
This project demonstrates the use of SQL for data validation, relational analysis, sales reporting, customer analysis, and business insight generation.
